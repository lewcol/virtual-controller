# VirtualController
## About
Desktop application providing a server which clients can connect to and act as virtual game controllers - as if a real controller is connected.
An Android client implementation is planned. Currently, the server is developed for Linux with the possibility of a Windows version in the future.

## Dependencies
- C++20
- CMake >= `3.20`
- Boost >= `1.90`
- OpenSSL >= `3.5.8`
- libprotobuf >= `3.19.6`
- protoc >= `36.2`

Older versions of the dependencies are currently untested, YMMV
